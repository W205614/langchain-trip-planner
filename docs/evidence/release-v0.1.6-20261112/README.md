## 问题与实际修复

| 问题 | 原因与处理 |
| --- | --- |
| 时间轴频繁过期 | 估算统一套用30分钟有效期；现在仅绑定实际使用的已核实事实有效期，无此类事实时明确为null。输入或事实变化、真正到期、旧记录缺少绑定仍失效 |
| RAG资料不可用 | 独立城市查询可能失败，且关闭、无结果与故障混为一谈；复用本次可信景点候选建索引，并分别报告三种状态 |
| 景点资料不全 | 供应商覆盖和确认级别有限；保留参考营业信息及来源，未知营业、预约、价格和接驳仍明确待核实，不伪造完整资料 |
| 照片不可用或重复下载 | 历史截图曾阻断外部请求；正常链路验证真实JPEG，并缓存校验成功的图片字节1小时、总量32MiB，失败不缓存或自动重试 |
| 地图不可见或署名溢出 | 浏览器SDK需要独立JS Key及正常网络；历史回放主动阻断。修正地图卡片布局，实际WebGL底图及完整署名已实拍 |

这些现象由应用流程、配置和历史截图采集边界共同造成，不能归结为高德MCP整体故障。高德参考数据仍不等于官方确认事实。
