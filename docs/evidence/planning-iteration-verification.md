# 本轮行程约束与可靠性验收

基于 7d2d306 的迭代。2026-09-10 本地采集；本文件记录本地验收，远程 CI 以对应提交的 GitHub Actions 为准。隔离验收不调用真实模型、高德、视觉或嵌入服务；测试使用隔离账户与合成资料。

| 验收项 | 结果 | 边界 |
|---|---|---|
| Windows pytest | 150 项通过 | 独立临时 SQLite、上游替身 |
| Docker PostgreSQL pytest | 150 项通过，15.67 秒 | 独立 trip_tests，已执行新增迁移 |
| 冻结约束评测 | 12/12；旧实现对同一组新增验收要求为2/12 | 定向困难案例，不是模型准确率；含新报告字段验收 |
| 原20场景 HTTP链路 | 20/20预期状态；16次成功保存；15/16规则通过 | fixture时延不能作为模型时延 |
| 前端镜像 | 类型检查与构建通过 | 保留既有大包体警告 |
| Playwright | 3项通过 | 任务列表、刷新恢复、约束提示持久化、编辑失败提示、账号隔离、服务端退出失效 |

| 运行中重启 | PROCESS_INTERRUPTED；重复键不重生成；未保存半成品 | 实际隔离容器重启，模型为替身 |

本地备份位于仓库外的 `E:/project/trip-planner-backups/pre-constraints-20260910-232125`，包含 PostgreSQL dump、应用数据包、校验清单和升级前计数。旧容器镜像层缺失，无法直接快照；已从原提交7d2d306重建前后端 `pre-constraints-20260910` 回退镜像。它们是源码重建结果，不是原镜像逐字节快照。
