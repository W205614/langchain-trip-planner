## 复现与实现边界

- 局部改排之前仅从允许修改的日期汇总全程状态，可能把未修改日期的 infeasible、not_found、unverified 隐藏成 feasible。现在从全部持久日期汇总；范围外日内容保持原样，缺少或过期的旧时间轴只能报待核实。
- 确认闭馆、预约或锁定窗口的矛盾独立于其他活动的缺失事实。现在保留这种已证明冲突；估算路线导致的接驳矛盾仍不能声称已经证明无解。
- 初始修复规则为 `time-windows-v6-conflict-classification`，上述开发／留出报告绑定该源码指纹。后续真实跨城评审发现原城接驳与固定交通未计入600分钟每日上限，已另加独立回归并修为 `time-windows-v7-whole-day-budget`；不重跑留出或重复付费生成来替换原结果。模型、提示、输入哈希和有效期一致时，旧候选与路线可继续复用，旧排程必须重新计算。
- 任务默认操作列表仍排除已保存结果与草稿。“全部任务”读取真实任务快照；普通草稿可显式恢复，已生成助手提案只能进入其预览确认／放弃流程。失败或取消的助手生成仍可恢复，不能把任务类型限制扩大到所有助手执行。
- 确认失败按稳定原因码说明事实过期、输入／版本变化、范围或保护活动冲突，页面保留提案。服务端拒绝写入的事务规则不变。
