## 安全复核材料

- `codeql/` 保留该基线 GitHub Actions [官方四语言分析](https://github.com/W205614/langchain-trip-planner/actions/runs/43179366950)的完整原始 SARIF。Java 原始 11 项、44 条完整路径逐项核对固定路径、回调接收对象和实际操作记账；其他三语言原始结果为 0。初次任务在分析上传后因旧源码绑定失败，原失败保留。
- `agent-raw-vulnerabilities.json` 保留当前候选镜像全部 226 项原始匹配，不降低严重度、不删除结果。`agent-source-native-review.json` 核对五处 Python 源码变化、实际镜像源码和原有原生文件谓词。
- 新增 glibc 两项告警对应四个精确包/漏洞组合，按当前调用路径评估，不声称 glibc 已修复：[CVE-2026-100290](https://security-tracker.debian.org/tracker/CVE-2026-100290)涉及 POSIX 正则内存分配失败；[CVE-2026-115819](https://security-tracker.debian.org/tracker/CVE-2026-115819)涉及宽字符 scanf 写入窄字符目标缓冲区。968 个 ELF 的实际导入检查与源码入口核对支持当前应用不进入受影响路径。管理员任意运行系统工具、新插件和未来原生调用不在结论内。

原始告警、适用性结论、实际修复和风险接受是不同概念。此处没有风险接受；最终镜像仍须通过全部级别扫描、实际源码绑定检查及最终提交 CI。
