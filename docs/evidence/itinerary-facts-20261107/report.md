## 验证结果

- 先复现 3 项改排／路线摘要失败；另单独复现未改动日期的过期路线被报告为 `feasible`。修复后直接相关 Python 回归 140 项通过，含数量冲突、范围保护、营业过期、路线恢复和旧日期保护。
- 真实浏览器 8 项通过，无失败、跳过或重试；覆盖事实说明、旧时间轴、未安排餐饮、工作台保存与局部范围。前端类型检查和构建通过。
- 使用既有 OpenAI 与高德凭据，在隔离 CLI 中实际生成杭州单日行程并改排，景点 2 → 1；使用 `gpt-6.1-sol` 与高德 MCP，新增文本 2 次、高德工具 54 次。原持久账本累计为文本 7/12、视觉 1/1、Embedding 23/40、高德 116/120，未清空或退款。
- 原行程的真实景点间路线为 32.62 公里、112 分钟，步行 0.713 公里，摘要现可回传这些数据。改排后只有一个景点，景点间没有路线段；其 0 公里只表示这一范围，不表示酒店与餐厅交通为零。
- 付费 CLI 抽样没有访问日常业务库、没有 Java 写回；HTTP 执行入口和浏览器行为分别由离线回归与 CI 验证。抽样前两次配置／时间边界准备失败均发生在供应商请求前，账本未增加。

本轮真实行程仍为 `degraded`：未提供出行日营业与预约确认、实际出发／住宿点，部分餐饮及路线信息尚不完整。代码错误已经修复；这些动态资料需要按实际旅行输入补充。历史样本与旧结果原样保留，新结果不改写旧样本成绩。
