# 单机质量与维护收敛

本轮范围为单机代码、测试入口和只读观测。没有启用备份、建设多机高可用或重新调用付费供应商；日常七服务保持用户原先的停止状态。日常镜像未被本轮测试替换。

## 实现与回归

- 每日模型输入与校验白名单共用候选选择，保留必去、已确认预约以及改排中的锁定／已完成景点。普通候选仍受4个预算约束；硬约束超出数量时继续交由求解报告冲突，不静默删除。
- 行前核验提供按日期、地点和跨城交通定位的补录清单，显示缺失、声明到期、冲突、未确认、无可用预约及闭馆。声明清单不替代服务端事实时效与可行性判断。表单拒绝无效时间、过期声明及超出允许范围的未来获取时间。
- 导出菜单改为明确点击打开，支持触屏与键盘激活，保留全部下载和离线交互断言。
- 结果页提案生命周期集中到 `useAssistantProposal`，API、差异展示和评审面板使用显式类型，保留原有版本冲突、事实过期、访问撤销与确认保护。
- 已审夹具迁入正式测试，CI直接执行原测试目录和脚本。两份Python夹具保持原断言；六份浏览器夹具保持原测试名称、超时及跳过标记，原期待数量未减少。迁移指纹见[fixture-migration.json](fixture-migration.json)。旧适配器与对应测试已移入[历史审计目录](retired-ci-adapters/)，它们依赖旧路径和旧源码，不再作为当前执行入口。
- HTTP排除日期的比较逻辑迁入正式评测模块，保留双方明确过期／未核实及其余全部JSON内容严格一致的约束；额外时间、POI、顺序、锁定、事实及有效性差异均有拒绝回归。
- `tools/single_host_inspection.py` 只读检查明确路径的宿主容量和可选的项目容器状态，默认容量低于10%返回非零；不启动服务，不修改备份计划。

## 仍需外部条件的事项

独立真人旅行评审、更多真实供应商场景和真实人员通知渠道未由本轮合成／离线测试完成。历史留出16/17不重写；没有新的真实准确率、费用账单或生产SLA声明。自动备份继续停用，没有有效恢复集。宿主容量检查不测量Linux卷内部空间、PostgreSQL WAL或单独的故障域。
