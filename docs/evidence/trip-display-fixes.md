# 行程显示与上海迪士尼必去要求修复

验证日期：2026-09-11。本机 Docker Compose，非线上 SLA。

## 根因与改动

- 必去名称此前只按完整名称匹配。用户输入“上海迪士尼公园”，高德返回“上海迪士尼度假区”和“上海迪士尼乐园”。现在优先精确匹配，仅在唯一候选时识别末尾“公园/乐园”的差异，不接受售票处或搜索首条替代；记录原始要求，在生成后补入并保护必去 POI。迪士尼乐园和环球影城采用 480 分钟规划预留，非官方最低游玩时长。
- 单日草稿没有酒店字段，已检索酒店此前没有写入行程。现在回填真实酒店候选，住宿按天数减一计算。
- 预算此前将交通固定为零，缺价景点与住宿亦呈现为零。现在明确区分模型估算与缺价预留；列出人数、房间数、晚数与预留标准，未知不意味着免费，显式零票价不被补价覆盖。
- 高德开放时间位于 `biz_ext.opentime2`；公交方案含 `walking_distance`。现在保留并显示这些字段。公交无方案时查询步行，仅接纳不超过 1.5 公里的真实步行方案，显示实际交通方式。保留上游失败状态，增加接口节流及一次 QPS 超限重试。
- 图片使用 POI ID 查询并尝试其他照片。本机代理将图片域名解析到 `198.18.0.0/15`，旧公网校验将其拦截。仅对 `https://store.is.autonavi.com:443/showpic/` 兼容该地址段，继续校验 TLS 和每次跳转，内网、其他域名及端口仍拒绝。

字段参考：[高德路径规划文档](https://lbs.amap.com/api/webservice/guide/api/direction)。开放时间字段与代理行为同时通过当前实际接口响应核实。

## 边界

开放时间是查询参考，不等于旅行当天营业已确认；预约要求、余票以及酒店/餐厅接驳与景区内部步行仍需确认。原有历史行程不会自动改写，重新生成后使用新的景点、预算和路线信息。未提交或推送 GitHub。

## 北京自驾截图问题补充修复（同日）

本次直接核对用户截图对应的已保存北京四日自驾行程，发现必去输入以单项 `北京故宫博物馆,天安门` 持久化。

- 输入层现在拆分英文/中文逗号、顿号、分号及换行，拆分后仍校验最多 8 项；前端标签输入同步支持分隔符。
- 新增统一名称解析服务，覆盖城市前缀、常用别名、博物馆/博物院及景区等名称差异。搜索、生成补入、必去保护、最终校验使用同一逻辑。出现同级分馆歧义时不静默选取；故宫内部交泰殿、出入口、售票处不能替代故宫主体。
- 一般“天安门”游览意图可以匹配天安门广场，“天安门城楼”不能据此判定已安排。别名按城市限定。
- 质量策略升级为 constraints-v2。历史详情读取时复用已保存路线证据更新名称与显示检查，不调用模型、不写回原始行程、不改变版本或景点顺序。结果页刷新旧检查时跳过尚未保存的用户编辑。
- 自驾场景显示“自驾路线不含停车后步行”，不再把不适用的步行指标显示为“待核实”，也不伪造为已核实的 0 公里。
- 高德照片旧 HTTP 地址升级 HTTPS，补齐 aos-cdn-image.amap.com/sns/ 与 aos-comment.amap.com/{POI}/headerImg/ 官方图片路径的 Fake-IP 兼容；仅允许对应 HTTPS/443 路径，仍拒绝内网及其它域名。application/octet-stream 通过 JPEG/PNG/GIF/WebP 文件标识识别，HTML 等非图片被拒绝。

最终本机逐图复测：这份北京行程的 11 个景点均返回 HTTP 200 的真实 JPEG，包括天安门广场和中国国家博物馆；无占位 SVG。该结果仅代表本次实际查询，不保证上游图片永久可用。

## 导出完整性与离线交互补充修复（同日）

用户进一步明确“无法操作”指下载的 PDF 无法展开、收起每天行程。当前 PNG/PDF 是静态输出，网页折叠交互不会随截图保留；新增“导出离线网页（可展开/收起）”，使用原生 details/summary，内嵌样式和图片，断网后可在浏览器中操作。

- 静态导出在独立副本中展开全部日期，不改变原页面的折叠状态；强制渲染未展开日期，防止遗漏后续行程。
- 导出图片改为立即加载，每张图等待上限 8 秒，失败使用占位；增加导出忙碌状态及画布尺寸限制，PNG 使用 Blob 下载。
- PDF 按 A4 页面切片，保留页边距，分页优先选择附近空白行；仍属于静态栅格 PDF，部分卡片或图片可能跨页。
- 离线 HTML 内嵌图片，不依赖远程脚本；内容安全策略限制网络与脚本执行。

验证：前端生产构建成功并更新本机 Compose 前端。Playwright 显示及导出回归合计 4 passed，覆盖慢图片、四天完整渲染、PNG/PDF 下载、离线 HTML 折叠及导出状态恢复。使用实际北京四日记录分别下载：PNG 为 1545 × 15530，PDF 为 7 页且可解析渲染；已查看全部 PDF 页面缩略图。实际离线 HTML 在浏览器断网状态下成功展开、收起第 4 天，图片内嵌。测试产物保存在忽略目录 .codex-live，未提交或推送。
