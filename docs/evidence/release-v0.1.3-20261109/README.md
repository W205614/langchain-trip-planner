# v0.1.3 验收范围

2026-11-09，本轮保留单机个人使用定位，修复显示问题并准备公开应用镜像。发布、Packages、最终 CI 和日常升级的实际状态以本轮 Release、工作流终态及本地交付记录为准，不将本文件作为预先通过的证明。

## 改动与本地验证

- 时间轴整体有效期失效时，活动标签同步显示“待核实”，不再保留“已确认安排”或“时间估算”。共享页面缺少依赖绑定时同样处理；不改写历史记录、锁定或完成状态。
- 两项真实浏览器回归在旧实现上失败，修复后通过；相关结果页、规划、PNG/PDF 和离线 HTML 回归合计 16 项通过，前端类型检查与构建通过。页面数据采用合成夹具，这组回归不证明真实供应商可用。
- 预制前端支持 `AMAP_WEB_JS_KEY` 运行时配置，不将模型或服务端 Key 传入浏览器。SDK 边界的浏览器用例验证运行时 Key 优先，并在 SDK 不可用时保留文字行程；没有调用真实地图 SDK。
- 新增源码材料收集和同一镜像推广工具。原始下载截断、错误路径及脚本失败记录保留在本地；源文件必须匹配固定校验值，缺失来源阻止分发，不降低门槛放行。

## 真实模型和高德抽样

通过实际浏览器注册隔离账号、提交杭州一日需求、Java/Agent/PostgreSQL 生成与持久化，再刷新查看结果。前端来源为 `ede533c`，Agent 使用既有 `v0.1.2` 应用层，Java 使用既有已验收应用层；后续分发许可层和浏览器 Key 配置另按最终制品验证，不把此样本冒充所有最终镜像的全量重测。

实际消耗 1 次文本模型调用和 46 次高德 MCP 工具调用；同一累计账本由文本 60/高德 1588 增至文本 61/高德 1634，未重置。模型为 `gpt-6.1-sol`，使用官方端点；RAG 和视觉未在这个样本中启用。

结果包含 1 天、2 个独立景点，生成模式 `llm`，实际时间求解完成，最终状态 `degraded`。营业、预约、餐厅、路线端点及超出近期天气范围等未知仍明确提示；不将该样本描述为旅行事实全部确认、一般准确率或生产容量证明。浏览器底图 SDK 请求在这项自动验收中阻断，高德 MCP 工具调用为真实请求，两者分开判断。

## 分发与维护边界

分发目标是三个 Linux/amd64 应用镜像、新版本源码、实际依赖源码/许可材料和摘要清单。Prometheus、Alertmanager、PostgreSQL 不在本轮重新分发；原备份与回退职责保留。新增手动 Packages 工作流仅用于推广经过验收的候选，不自动重建、不覆盖既有版本、不部署生产。

操作入口见[容器分发手册](../../operations/container-distribution.md)。日常环境保持既有业务卷、上传、索引、账号和私有配置，升级验收后恢复原停止状态；自动备份保持停用。真实公网 SMTP、S3、TLS、异地恢复、多实例和真实预订支付不在本轮新增验收范围。
