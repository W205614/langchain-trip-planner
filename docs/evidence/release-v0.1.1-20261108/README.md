# v0.1.1 补丁验收与升级

2026-11-08。相对 `v0.1.0`，本次是兼容修复，没有新增依赖、数据库迁移或破坏性 API 变化。项目仍面向单机部署与个人日常使用，保留 `v0.1.0` 原标签。

## 修复范围

- 排程或约束处理减少景点时，保存调整前后数量，在结果页明确提示；历史查询保留已经产生的调整说明。
- 最终删减、调序或跨日交换后，同步主题与描述，清除引用旧景点的自由活动建议；未变化日期及既有历史行程不自动改写。
- 因默认排程时间或查询次数预算耗尽而未发送的路线，恢复后可首次查询。已发送成功或失败的路线继续遵循去重、有效期与不自动重试策略。
- 规则版本为 `time-windows-v10-adjustment-resume`。兼容草稿和供应商事实可以复用，旧排程重新计算；旧 v9 未知路线无法区分是否发送过，不批量重发或续期。
