## 行为变化

- 排程或约束处理减少景点时，记录调整前后数量和移除的景点，在结果页明确显示原数量未保留。该提示不会通过强行添加景点来破坏时间、必去或保护约束；历史查询保留已产生的调整说明。
- 最终景点发生删减、调序或跨日交换后，主题和描述按最终景点同步，清除可能仍引用旧景点的自由活动建议。未改动日期、未变化的叙述以及只读历史查询保持原内容。
- 预算耗尽而尚未发送的路线查询只在当前阶段估算，不再持久化为已发送失败。恢复时可以首次查询延后路线，已发送成功或失败的路线沿用原有去重与有效期策略。
- 排程规则升级为 `time-windows-v10-adjustment-resume`。允许兼容的旧草稿和供应商事实复用，旧已解排程重新核验。旧 v9 的未知路线无法追溯是否真实发送过，本次补丁不会将它们批量重发或续期。
